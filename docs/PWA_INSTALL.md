# Instalasi PWA

> Status: **dijadwalkan pada Fase 8.** Manifest, service worker, ikon, splash
> screen, dan tombol instal belum aktif. Dokumen ini akan dilengkapi saat
> Fase 8 selesai.

Rencana:

- Android (Chrome): menu ⋮ → **Instal aplikasi** / **Tambahkan ke layar utama**.
- iPad/iPhone (Safari): tombol Bagikan → **Tambahkan ke Layar Utama**.
- Desktop (Chrome/Edge): ikon instal di address bar.

PWA ini **bukan POS offline**: login, membaca data, menyimpan transaksi, dan
mengubah stok tetap memerlukan internet. Saat offline aplikasi menampilkan
indikator dan menolak penyimpanan.
